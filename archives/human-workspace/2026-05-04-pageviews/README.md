# Pageviews Archive

This directory retains the Pageviews candidate selection/submission scripts and their
captured output as historical reference artifacts.

The artifacts are reference-only. Active source selection and submission entrypoints
belong under `apps/operator_tools`.

On 2026-05-04, a dry run of the Pageviews submission script reported 3108 input
candidates and 3108 already processed page ids, with zero units to insert.
